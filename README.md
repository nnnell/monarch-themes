# Monarch themes

Add any of these JSON files to your Monarch themes directory in `~/Library/Application Support/com.monarch.macos/themes/`.

If you aren’t sure how to get to your home Library folder: Open a Finder window, press `Shift` + `⌘` + `G`, and type in `Library`. From there, you should be able to find the `Application Support` folder, then locate the `com.monarch.macos` folder, and find the `themes` folder within it.
